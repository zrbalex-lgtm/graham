# Число Грэма на пальцах

Домашний доклад на ~30 минут для детей: от одной точки до g₆₄.
По мотивам [waitbutwhy](https://waitbutwhy.com/2014/11/1000000-grahams-number.html).

**Открыть:** [index.html](index.html) — или через GitHub Pages, если он включён.

## Как показывать

Ноутбук по HDMI, страница на весь экран. Любой презентационный кликер
шлёт стрелки и работает как есть.

| Клавиша | Что делает |
|---|---|
| → / пробел / клик | дальше (внутри слайда — следующий такт) |
| ← | назад |
| `N` | заметки докладчика — подсказки по текущему слайду |
| `F` | во весь экран |
| Home / End | первый / последний слайд |

Параметр `?all` в адресе раскрывает все такты сразу — удобно, чтобы
пролистать глазами или напечатать.

## Что внутри

```
index.html        33 слайда
assets/style.css  оформление
assets/deck.js    навигация, рисовалки, анимации, интерактив
img/              картинки для слайдов 12, 13, 14, 15, 24, 29
docs/script-full.md  полный сценарий: что говорить + описание картинок
docs/speech.pdf      только речь, по слайдам, для печати
```

Картинки — обычные файлы в `img/`, имя = номер слайда (`12.webp` и так далее).
Чтобы заменить иллюстрацию, достаточно положить новый файл под тем же именем.
Если файла нет, слайд просто покажется без него.

Остальная графика рисуется кодом при открытии страницы: поля точек
(в том числе честный миллион), башни из троек, стена стрелок, графы,
луч света, колода карт. Эффект мела — SVG-фильтр `chalky` в начале `index.html`.

## Интерактивные места

Четыре штуки, все открываются последним тактом своего слайда — чтобы не
отвлекали, пока идёт рассказ.

- **Слайд 15** — ползунок степени десятки: от одной точки до гугола, с
  подписью, что столько бывает в реальности.
- **Слайд 23** — ползунок «добавь тройку в башню»: видно, как от третьей
  тройки к шестой число перестаёт помещаться в описание.
- **Слайд 27** — кнопки по уровням стрелок, от одной до g₁ штук.
- **Слайд 31** — раскраска рёбер в два цвета. Дети пробуют обойтись без
  одноцветного треугольника; на шести точках это невозможно — это теорема
  Рамсея R(3,3) = 6, та же идея, из которой выросла задача Грэма.

## Нумерация слайдов

`docs/speech.pdf` ссылается на номера слайдов. Если добавляешь или удаляешь
слайд — нумерация поедет, и PDF надо пересобрать. Интерактив специально
добавлен тактами внутри существующих слайдов, чтобы номера не менялись.
